# RTL-FIX

ابزاری ساده و تک‌فایلی برای نوشتن و پیش‌نمایش متن‌های Markdown با پشتیبانی کامل از راست‌به‌چپ (RTL) و فارسی.

## ⚠️ توضیح مهم

> **این ابزار کاملاً توسط هوش مصنوعی (AI) ساخته شده است.**
> من فقط آن را جمع‌آوری و سر هم کرده‌ام تا در صورت نیاز، خودم و دیگران بتوانند از آن استفاده کنند. هیچ ادعایی روی نویسندگی یا طراحی کد ندارم.

## این ابزار برای چه کسانی مفید است؟

خیلی وقت‌ها متن‌هایی به‌صورت Markdown (خروجی چت‌بات‌ها، فایل‌های `.md` و...) در اختیارمان قرار می‌گیرد، اما جایی برای دیدن نسخه‌ی درست و **راست‌چین‌شده‌ی** آن‌ها نداریم — بیشتر ویرایشگرهای آنلاین Markdown فقط چپ‌به‌راست (LTR) هستند و متن فارسی/عربی در آن‌ها به‌هم‌ریخته نمایش داده می‌شود.

این صفحه دقیقاً همین مشکل را حل می‌کند: متن Markdown را وارد کنید (یا پیست کنید)، خروجی تمیز و راست‌چین را همان‌جا ببینید.

## امکانات

- ✍️ **ویرایشگر + پیش‌نمایش زنده**، هر دو کاملاً راست‌به‌چپ
- 🖊️ حالت **تمام‌صفحه (Modal)** برای نوشتن متن‌های طولانی‌تر
- 🎨 پشتیبانی از سینتکس Markdown رایج:
  - عنوان‌ها (`#` تا `######`)
  - لیست‌های نقطه‌ای و شماره‌دار
  - نقل‌قول (`>`)
  - بلوک‌های کد با هایلایت رنگی (`highlight.js`)
  - خط افقی (`---`)
  - **جدول‌ها (Table)** با پشتیبانی از چینش ستون‌ها (راست، چپ، وسط)
  - بولد، ایتالیک و لینک‌های درون‌خطی
- 💾 **ذخیره‌سازی خودکار** متن در `localStorage` مرورگر (نیازی به سرور یا اینترنت نیست)
- 🕘 بخش **تاریخچه**: نسخه‌های قبلی متن به‌صورت خودکار ذخیره می‌شوند و می‌توان آن‌ها را بازگردانی یا حذف کرد
- 📋 دکمه‌ی **کپی خروجی** برای کپی سریع نسخه‌ی نهایی
- 🌙 طراحی تیره (Dark Mode) و فونت وزیرمتن برای خوانایی بهتر فارسی

## نحوه‌ی استفاده

۰. برای دسترسی به پروژه می‌توانید از [Preview](https://htmlpreview.github.io/?https://github.com/alir3za-samadi/RTL-FIX/blob/main/RTL-FIX-V3.html) (حالت اجراشدهٔ `index.html` همین مخزن) یا [Demo](https://rtl-fix.freedev.app/) استفاده کنید.

۱. فایل `RTL-FIX-V3.html` را در هر مرورگری باز کنید (نیازی به نصب یا سرور نیست).
۲. متن Markdown خودتان را در جعبه‌ی ویرایشگر بنویسید یا پیست کنید.
۳. پیش‌نمایش راست‌چین و تمیز آن را بلافاصله در همان صفحه ببینید.
۴. در صورت نیاز از دکمه‌ی «کپی خروجی» برای گرفتن نسخه‌ی نهایی استفاده کنید.

> از آنجا که همه‌چیز در همان مرورگر و با `localStorage` ذخیره می‌شود، اطلاعات شما جایی ارسال نمی‌شود و کاملاً محلی (local) باقی می‌ماند.

## محدودیت‌ها

- این یک پیاده‌سازی ساده و سبک از Markdown است، نه یک پارسر کامل و استاندارد (مثل `marked.js` یا `remark`)؛ برخی سینتکس‌های پیشرفته‌ی Markdown ممکن است پشتیبانی نشوند.
- تاریخچه فقط در همان مرورگر و همان دستگاه ذخیره می‌شود و بین دستگاه‌های مختلف همگام‌سازی نمی‌شود.
